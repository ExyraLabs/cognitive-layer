## Running Examples

### Prerequisites

1. Clone the cognitive layer repository
2. Install dependencies: `npm install`
3. Set up environment variables in `.env`
4. Compile TypeScript: `npm run build`

### Basic Usage

```bash
# Run a simple example
npx ts-node examples/basic-setup.ts

# Run with specific configuration
npx ts-node examples/yield-farming-bot.ts

# Run backtesting example
npx ts-node examples/backtesting.ts
```

### Advanced Examples

```bash
# Multi-chain coordination
npx ts-node examples/multi-chain-coordinator.ts

# Real-time dashboard
npx ts-node examples/dashboard.ts

# Custom agent implementation
npx ts-node examples/custom-agent.ts
```
